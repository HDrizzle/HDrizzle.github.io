Evolution Simulator - Hadrian Ward

A long time ago I watched Youtube video about simulating evolution. I set out to recreate it on my own. I originally built it in Python which was really slow because of the O(N^2) vision algorithm. I had it running on my RPi Zero W for a while. Eventually I rewrote it in Rust which made it much faster. It is currently running on my RPi right now (as long as the power doesn't go out). Eventually once I get an actual domain I will put a link to it here.
